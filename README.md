## 🏥 3 ప్రధాన విభాగాలు (Three Core Services)
1. **మనుషుల మందులు (Human Medical Store):**
   - జ్వరం, జలుబు, బీపీ, షుగర్, నొప్పులు, విటమిన్లు, చిన్నారుల మందులు మరియు ప్రథమ చికిత్స సామాగ్రి.

2. **పశువులు, గొర్రెల, మేకల మందులు (Veterinary Medical Store):**
   - *"మావద్ద పశువుల, గొర్రెల, మేకల మందులు లభించును"*.
   - పాడి ఆవులు, గేదెలు, గొర్రెలు, మేకలు, కోళ్ళు మరియు కుక్కలకు నట్టల మందులు (Deworming), హై-కాల్షియం జెల్స్, మినరల్ మిక్చర్, పాల దిగుబడి టానిక్కులు, పేలు-గోమార్ల స్ప్రేలు.
   - పశువుల మందుల ఆర్డర్ ఫారం & పశువైద్యుడి సంప్రదింపుల మార్గదర్శక నోట్.

3. **క్లినిక్ (People Clinic Only - కేవలం మనుషులకు మాత్రమే!):**
   - అనుభవజ్ఞులైన లేడీ డాక్టర్ `[వైద్యురాలి పేరు], RMP` గారి పర్యవేక్షణలో మహిళలు, పిల్లలు, వృద్ధులకు ప్రాథమిక పరీక్షలు, బీపీ-షుగర్ చెకింగ్, గాయాలకు డ్రెస్సింగ్, జ్వరం చికిత్స.
   - (గమనిక: పశువుల చికిత్స క్లినిక్‌లో చేయబడదు).

## ⚙️ వివరాలు మార్చడం ఎలా? (How to Edit Store Info)
కేవలం ఒకే ఒక్క ఫైల్ **`js/config.js`** ఓపెన్ చేసి క్రింది వివరాలను మార్చుకుంటే, వెబ్‌సైట్ మొత్తం ఆటోమేటిక్‌గా అప్‌డేట్ అవుతుంది:
- `shopNameEn` / `shopNameTe`: షాపు పేరు
- `proprietorEn` / `proprietorTe`: ప్రొప్రైటర్ పేరు
- `contact.primaryPhone`: ప్రాథమిక ఫోన్ నంబర్ (`8008200947`)
- `contact.secondaryPhone`: రెండవ ఫోన్ నంబర్ (`9603232767`)
- `contact.whatsappNumber`: వాట్సాప్ నంబర్ (`918008200947`)
- `doctor.nameTe`: లేడీ డాక్టర్ గారి పేరు (`[వైద్యురాలి పేరు], RMP`)
- `licences`: డ్రగ్ లైసెన్స్ నంబర్లు

## 🚀 హోస్టింగర్ లో డిప్లాయ్ చేయడం ఎలా? (Step-by-Step Hostinger Deployment)

ఈ వెబ్‌సైట్ ఎటువంటి కంపైలేషన్ లేదా సర్వర్ బిల్డ్ లేకుండా పనిచేసే ప్యూర్ స్టాటిక్ వెబ్‌సైట్. కాబట్టి హోస్టింగర్‌లో 1 నిమిషంలో సులభంగా లైవ్ చేయవచ్చు:

### స్టెప్ 1: ఫైల్స్‌ను జిప్ (ZIP) చేయడం
1. మీ కంప్యూటర్‌లో `medical shop` ఫోల్డర్‌ను ఓపెన్ చేయండి.
2. లోపల ఉన్న అన్ని ఫైల్స్ మరియు సబ్-ఫోల్డర్లను సెలెక్ట్ చేయండి:
   - `index.html`, `human-medicines.html`, `animal-medicines.html`, `clinic.html`, `about.html`, `delivery-info.html`, `contact.html`, `terms.html`, `disclaimer.html`, `privacy-policy.html`, `404.html`
   - `.htaccess`, `sitemap.xml`, `robots.txt`
   - `css/`, `js/`, `assets/` ఫోల్డర్లు
3. Right Click చేసి **"Compress to ZIP file"** సెలెక్ట్ చేసి `website.zip` అని పేరు పెట్టండి.

### స్టెప్ 2: Hostinger hPanel లో అప్‌లోడ్ చేయడం
1. మీ **Hostinger Account** (hPanel) లో లాగిన్ అవ్వండి.
2. **Websites** లో మీ డొమైన్ పక్కన ఉన్న **Manage** క్లిక్ చేయండి.
3. ఎడమవైపు మెనూ నుండి **File Manager** (Files -> File Manager) ను ఓపెన్ చేయండి.
4. `public_html` ఫోల్డర్‌పై డబుల్ క్లిక్ చేసి లోపలికి వెళ్ళండి (ఇది మీ వెబ్‌సైట్ రూట్ డైరెక్టరీ).
5. పైన ఉన్న **Upload** బటన్ క్లిక్ చేసి మీరు తయారు చేసిన `website.zip` ను అప్‌లోడ్ చేయండి.
6. అప్‌లోడ్ అయిన `website.zip` పై Right Click చేసి **Extract** నొక్కండి (ఫోల్డర్ నేమ్ అడిగితే కేవలం `.` లేదా ఖాళీగా ఉంచండి).
7. ఇప్పుడు `public_html` లో నేరుగా `index.html`, `.htaccess`, `sitemap.xml`, `css`, `js`, `assets` మొదలైనవి కనిపిస్తాయి.
8. మీ బ్రౌజర్‌లో మీ డొమైన్ (ఉదా: `https://yourdomain.com`) ఓపెన్ చేసి చూడండి. వెబ్‌సైట్ వెంటనే లైవ్ అవుతుంది!

## 🔍 గూగుల్ సెర్చ్ కన్సోల్ (Google Search Console) లో వెరిఫికేషన్ పాస్ అవ్వడం ఎలా?

గూగుల్ సెర్చ్ కన్సోల్ (GSC) లో మీ వెబ్‌సైట్ ఓనర్‌షిప్ 100% ఎర్రర్స్ లేకుండా పాస్ అవ్వడానికి 2 సులువైన పద్ధతులు ఉన్నాయి:

### పద్ధతి 1: HTML Tag వెరిఫికేషన్ (అత్యంత సులభం - Most Recommended)
1. **[Google Search Console](https://search.google.com/search-console)** వెబ్‌సైట్‌కి వెళ్ళండి.
2. మీ జీమెయిల్ (`zippyenterprises26@gmail.com`) తో లాగిన్ అవ్వండి.
3. **Add Property** క్లిక్ చేసి, కుడివైపు ఉన్న **URL prefix** బాక్స్‌లో మీ వెబ్‌సైట్ పూర్తి లింక్ ఇవ్వండి (ఉదా: `https://yourdomain.com`).
4. **Continue** క్లిక్ చేసినప్పుడు వెరిఫికేషన్ ఆప్షన్స్ కనిపిస్తాయి. అందులో **HTML tag** ఆప్షన్‌ను సెలెక్ట్ చేయండి.
5. అక్కడ మీకు ఒక కోడ్ కనిపిస్తుంది:
   `<meta name="google-site-verification" content="abcdef1234567890..." />`
6. ఆ `content="..."` లోని కోడ్‌ను కాపీ చేయండి.
7. మీ `index.html` ఫైల్‌లో **16వ లైన్** లో ఉన్న:
   ```html
   <meta name="google-site-verification" content="YOUR_GOOGLE_SEARCH_CONSOLE_VERIFICATION_CODE_HERE">
   ```
   స్థానంలో మీ కోడ్‌ను పేస్ట్ చేసి ఫైల్‌ను సేవ్ చేయండి (Hostinger File Manager లో నేరుగా Edit చేయవచ్చు).
8. Google Search Console లో **"Verify"** బటన్ క్లిక్ చేయండి. **"Ownership verified"** అని గ్రీన్ టిక్ మార్క్ తో సక్సెస్ అవుతుంది!

### పద్ధతి 2: HTML File Upload వెరిఫికేషన్
1. Google Search Console లో **HTML file** ఆప్షన్ సెలెక్ట్ చేస్తే, గూగుల్ ఒక చిన్న ఫైల్‌ను డౌన్‌లోడ్ చేయమని ఇస్తుంది (ఉదా: `google123456789.html`).
2. ఆ ఫైల్‌ను డౌన్‌లోడ్ చేసి, మీ Hostinger `public_html` ఫోల్డర్‌లో అప్‌లోడ్ చేయండి.
3. Search Console లో **"Verify"** క్లిక్ చేయండి. వెంటనే వెరిఫై అయిపోతుంది!

## 🛡️ ఎర్రర్స్ రాకుండా తీసుకున్న జాగ్రత్తలు (100% Error-Free Architecture)
- **HTTPS Enforcement (.htaccess):** HTTP ట్రాఫిక్ ఆటోమేటిక్‌గా సెక్యూర్ HTTPS కి మళ్ళుతుంది. డూప్లికేట్ ఎర్రర్స్ రావు.
- **Canonical URLs:** ప్రతి పేజీకి కరెక్ట్ కానానికల్ ట్యాగ్ ఉంది. "Duplicate without user-selected canonical" ఎర్రర్ రాదు.
- **Soft 404 Prevention:** కస్టమ్ `404.html` లో `noindex` సెట్ చేయబడింది.
- **Mobile Friendly:** ఫాంట్ సైజులు పెద్దవిగా ఉంచబడ్డాయి. వ్యూపోర్ట్ ట్యాగ్ మరియు రెస్పాన్సివ్ కంటైనర్లు ఉన్నందున మొబైల్ యూజబిలిటీ ఎర్రర్స్ రావు.
- **Schema.org Structured Data:** గూగుల్ లోకల్ బిజినెస్ / ఫార్మసీ రిచ్ రిజల్ట్స్ కోసం లోకల్ స్కీమా యాడ్ చేయబడింది.
